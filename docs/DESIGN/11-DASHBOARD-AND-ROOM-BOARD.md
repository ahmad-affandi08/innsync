# Dashboard and Room Board

Dashboard is a read model, not a write authority. Every metric links to source detail where PRD requires drill-down.

Room state must not collapse multiple dimensions into one ambiguous string. Present at least occupancy, housekeeping readiness, sellability, and service flags. `Complimentary` is rate/folio information, not housekeeping state.

Avoid a wall of KPI cards. Use a compact top summary, operational room board, prioritized exception list, then supporting trends.
