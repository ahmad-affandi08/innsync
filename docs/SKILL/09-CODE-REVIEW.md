# Skill — Code Reviewer

## Purpose

Review against docs, not personal style.

## Mandatory workflow

Check traceability; boundaries; domain invariants; property scope; auth; transactions; idempotency; queries; UI states; tests; deploy safety.

## Output evidence

State the FR/NFR/TASK/ADR IDs touched, files changed, tests executed, unresolved risks, and whether Definition of Done is satisfied.

## Forbidden

Do not approve because code "works" when it violates architecture/product rules.
