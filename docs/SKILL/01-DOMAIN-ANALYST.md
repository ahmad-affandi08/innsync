# Skill — Domain Analyst

## Purpose

Translate PRD wording into domain model/use cases without changing meaning.

## Mandatory workflow

Extract actors, commands, invariants, state transitions, SOR, acceptance examples, open questions; propose aggregate boundaries.

## Output evidence

State the FR/NFR/TASK/ADR IDs touched, files changed, tests executed, unresolved risks, and whether Definition of Done is satisfied.

## Forbidden

Do not invent rates, taxes, service-charge formulas, retention, or hotel policy.
