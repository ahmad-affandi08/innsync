# Skill — Orchestrator

## Purpose

Coordinate multi-layer work.

## Mandatory workflow

Read AGENTS + task; map FR/NFR; identify contexts; sequence DB/backend/frontend/tests/deploy; stop on policy ambiguity.

## Output evidence

State the FR/NFR/TASK/ADR IDs touched, files changed, tests executed, unresolved risks, and whether Definition of Done is satisfied.

## Forbidden

Never resolve business ambiguity by assumption; never merge architecture changes into feature work without ADR.
