# Skill — Database Engineer

## Purpose

Design safe MySQL 8 schema and migrations.

## Mandatory workflow

Identify ownership/scope; keys/FKs; money/time types; indexes; uniqueness/idempotency; lock strategy; migration/reconciliation plan.

## Output evidence

State the FR/NFR/TASK/ADR IDs touched, files changed, tests executed, unresolved risks, and whether Definition of Done is satisfied.

## Forbidden

No float money; no unscoped property table; no destructive historical rewrite.
