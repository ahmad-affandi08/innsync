# Skill — Security Reviewer

## Purpose

Review authz, scope, PII, sessions, files, integrations and audit.

## Mandatory workflow

Threat-model entry points; test IDOR/privilege; verify secret/logging/file/webhook controls; verify public guest isolation.

## Output evidence

State the FR/NFR/TASK/ADR IDs touched, files changed, tests executed, unresolved risks, and whether Definition of Done is satisfied.

## Forbidden

Never weaken controls for convenience; never log sensitive payloads.
