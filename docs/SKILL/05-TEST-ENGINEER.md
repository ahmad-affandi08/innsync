# Skill — Test Engineer

## Purpose

Prove FR/NFR behavior and regression safety.

## Mandatory workflow

Derive scenario matrix from acceptance/invariants; test negative/concurrency/retry/offline/security; capture evidence.

## Output evidence

State the FR/NFR/TASK/ADR IDs touched, files changed, tests executed, unresolved risks, and whether Definition of Done is satisfied.

## Forbidden

Do not accept only happy-path tests or coverage percentage as proof.
