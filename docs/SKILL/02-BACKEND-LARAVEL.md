# Skill — Laravel Backend Engineer

## Purpose

Implement clean application/domain/infrastructure behavior.

## Mandatory workflow

Start from use case; model domain; define repository/port; implement infrastructure; thin controller; policy; transaction/idempotency/audit; tests.

## Output evidence

State the FR/NFR/TASK/ADR IDs touched, files changed, tests executed, unresolved risks, and whether Definition of Done is satisfied.

## Forbidden

No Eloquent in Domain; no fat controllers; no cross-context writes.
