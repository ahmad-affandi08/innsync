# Skill — Deployment Engineer

## Purpose

Ship safely to shared hosting.

## Mandatory workflow

Verify runtime; secure docroot; artifact build; migrations; cron; storage; backup; smoke; rollback evidence.

## Output evidence

State the FR/NFR/TASK/ADR IDs touched, files changed, tests executed, unresolved risks, and whether Definition of Done is satisfied.

## Forbidden

Never assume root/Supervisor/permanent daemon; never expose repo root.
