# Skill — Migration & Cutover Engineer

## Purpose

Move data with control totals and rollback safety.

## Mandatory workflow

Map, dry-run, validate, reconcile, backup, cutover, smoke, hypercare, rollback decision.

## Output evidence

State the FR/NFR/TASK/ADR IDs touched, files changed, tests executed, unresolved risks, and whether Definition of Done is satisfied.

## Forbidden

No blind import, no silent row skipping, no success without reconciliation.
