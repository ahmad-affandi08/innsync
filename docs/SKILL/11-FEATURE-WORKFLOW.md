# Skill — End-to-End Feature Workflow

1. Read the task and PRD requirement(s).
2. Confirm no open PRD question blocks implementation.
3. Identify context/aggregate/system-of-record.
4. Write acceptance examples and negative cases.
5. Design migration/schema/index/lock if needed.
6. Implement Domain first when behavior exists.
7. Implement Application use case and ports.
8. Implement Infrastructure adapters/persistence.
9. Implement authorization and HTTP/Inertia adapter.
10. Implement frontend with standard states and design primitives.
11. Add automated tests and regression cases.
12. Run format/static analysis/typecheck/build/tests.
13. Review security/property/idempotency/audit.
14. Update task traceability/evidence.
15. Only then mark REVIEW/DONE.
